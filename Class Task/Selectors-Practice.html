Examples of element, class, ID, attribute and combinator selectors with short explanations.

Element selector

This paragraph is targeted by the element selector p { ... }.

Element selectors match all elements of that type.

Class selector

This paragraph uses the .highlight class.

Multiple classes work too: .badge.highlight

ID selector

This paragraph has an ID and is styled with #special. IDs are unique per page.

Attribute selectors

Links with href starting with https are selected with a[href^="https"]:

Secure link (https) — will be styled by the attribute selector.

Non-secure link (http) — not matched by the selector above.

Combinators

Parent > Child (direct child)

Direct child > matches this paragraph (immediate child of .parent).

Nested deeper — still a descendant but not a direct child.

Adjacent sibling (+)

Heading

Paragraph immediately after an h4 — matched by h4 + p.

This paragraph is a sibling but not adjacent to the h4.

General sibling (~)

Start

First sibling matched by h4 ~ p.

Second sibling also matched by the general sibling selector.

Descendant (space)

Any p inside an .outer element is matched by .outer p.
