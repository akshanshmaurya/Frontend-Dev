Box-Sizing Comparison

Demonstrates the difference between the default box model and box-sizing: border-box.

Each example uses the same width and padding values. Notice how the total rendered size differs when the default box-sizing is used versus border-box, which includes padding and border in the element's declared width.

Default box-sizing

Declared width: 200px
Padding: 20px
Border: 8px

box-sizing: border-box
