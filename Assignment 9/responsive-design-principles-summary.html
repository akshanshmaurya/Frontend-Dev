Responsive Design Principles

Core Concepts

Fluid Layouts

Use percentage-based widths to let containers expand or shrink with the viewport.

.container { width: 90%; margin: 0 auto; }

Flexible Media

Keep images inside their parent with max-width: 100% and auto height.

img { max-width: 100%; height: auto; }

Breakpoints

Introduce media queries where layout shifts improve usability.

@media (max-width: 768px) { ... }
